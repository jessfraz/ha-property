# Property

Keep property tax notices, assessments, balances and payment evidence in one
ledger. Open the web UI after installation and add the Property integration in
Home Assistant for sensors and a read-only deadline calendar.

Resolve the address and confirm the exact county parcel before collecting.
LA sync reads payment history and published assessment rolls; source gaps stay
explicit. The current bill-viewer lookup is unverified and the balance viewer
requires human reCAPTCHA verification. Missing results never mean no tax is due.
Manual evidence import remains available. No support requests or payments are
submitted, and no account or existing calendar is changed.

Native HA cold backups cover the app's data. Stop the app before a manual copy.
